# PlugV Image Standards

## Purpose

Photography and visuals should create trust before the user reads a word. Every image in PlugV should feel premium, calm, modern, and decision-focused.

## Visual Style

PlugV imagery should be:

- Premium

- Minimal

- Modern

- India-first

- Calm

- Trustworthy

- Technology-forward

Images should never feel cluttered, noisy, or overly promotional.

## Image Categories

PlugV images should be organized into these groups:

- **Hero**: flagship images for the homepage and major landing pages

- **Vehicles**: EV product images used on vehicle pages and cards

- **Charging**: charging station and route-planning imagery

- **Lifestyle**: real-world EV usage, family, commuting, road trips

- **About**: founder, company, mission, and brand imagery

- **Backgrounds**: gradients, soft textures, ambient visuals

- **Textures**: overlays, grids, glass effects, subtle visual layers
