## Required record for future assets

For every new third-party or commissioned asset record: public file path, creator/source, licence or written permission, permitted commercial use, attribution requirement, acquisition date, evidence location and approving person. AI-generated assets must retain the prompt, generation date, tool/provider, original output and a human review for misleading brand resemblance.
